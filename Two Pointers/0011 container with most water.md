# Container With Most Water

**LeetCode 11 · Container With Most Water**  
**难度：Medium | 方法：双指针**

---

## 思路

给你一排柱子，找两根柱子围成的最大水容量。

**口诀：双指针从两端夹，算面积更新res，矮的往里移，相遇就返回**

**为什么移动矮的？**
- 留着矮的没用，面积永远被矮的限制
- 移动矮的才有可能找到更高的柱子，面积才有可能变大
- 移动高的只会让距离变小，面积只会更小

---

## 代码

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        # 存历史最大面积，初始为 0
        res = 0
        # 左指针从第 0 位出发，右指针从最后一位出发
        l, r = 0, len(height) - 1
        # 左右指针还没相遇就继续循环
        while l < r:
            # 当前面积 = 两指针距离 × 较矮的柱子高度
            area = (r - l) * min(height[l], height[r])
            # 更新历史最大面积
            res = max(res, area)
            # 如果左边柱子比右边矮，左指针往右移
            if height[l] < height[r]:
                l += 1
            # 否则右边更矮或一样高，右指针往左移
            else:
                r -= 1
        # 返回最大面积
        return res
```


---

## 例子演示

`height = [1, 8, 6, 2, 5]`

```
l=0, r=4  area = (4-0) * min(1,5) = 4*1 = 4   res=4   height[0]=1 < height[4]=5 → l+=1
l=1, r=4  area = (4-1) * min(8,5) = 3*5 = 15  res=15  height[1]=8 > height[4]=5 → r-=1
l=1, r=3  area = (3-1) * min(8,2) = 2*2 = 4   res=15  height[1]=8 > height[3]=2 → r-=1
l=1, r=2  area = (2-1) * min(8,6) = 1*6 = 6   res=15  height[1]=8 > height[2]=6 → r-=1
l=1, r=1  l == r → 停止

答案：15
```

---

## 关键点

- `len(height) - 1` 是最后一个元素的下标，因为下标从 0 开始
- 面积用 `min` 不是 `max`，因为水从矮的地方溢出
- `l += 1` 是左指针往右移，`r -= 1` 是右指针往左移，永远往里收缩
- 当前面积存进 `area`，历史最大存进 `res`，两个变量不一样

---

## 时间复杂度

- Time: O(n)
- Space: O(1)
